# To-Do List

A fast, persistent, and accessible task manager built with vanilla JavaScript, keyed DOM reconciliation, `localStorage`, and a modular `esbuild` asset pipeline.

## Live Demo

- **Live Site:** [https://evancru-todo-list.netlify.app](https://evancru-todo-list.netlify.app) *(Update with your Netlify URL)*

## Features

- **Full Task CRUD & Reordering:** Add tasks, toggle completion, edit task text inline (`Enter` to save, `Escape` to cancel), delete tasks, and reorder items up or down.
- **Keyed DOM Reconciliation:** Diffs existing task nodes by unique `data-id` keys using a `Map` to update and move only changed elements without full list re-renders.
- **Instant Filtering & Bulk Actions:** Filter views by **All**, **Active**, or **Completed**, plus one-click **Clear Completed** and **Clear All** (with confirmation).
- **Persistent Storage:** Automatically syncs tasks to `localStorage`.
- **Accessible & Responsive:** WCAG AA color contrast, high-visibility `:focus-visible` keyboard outlines, descriptive `aria-label` attributes, and mobile-first responsive layouts (100/100 Lighthouse scores).

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/cuduco19/todo.git
   cd todo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Build production assets:**
   ```bash
   npm run build
   ```

4. **Preview locally:**
   Open `index.html` using a local development server (such as VS Code Live Server).

## Deployment

Configured for static deployment on **Netlify** directly from GitHub:
- **Publish directory:** `.` (root)
- **Production assets:** Pre-bundled inside `dist/` via `esbuild`
